# 泰康车险小程序

这是独立微信原生小程序源码。Java 后端与两个网页端位于上级工程的其他目录；本目录不依赖旧企业微信系统。使用微信开发者工具直接导入，无须 npm 编译。

## 启动

1. 先按总工程说明启动 Java 后端。
2. 微信开发者工具 → 导入项目 → 选择本目录。将 `project.config.json` 中 `appid` 改为你的真实小程序 AppID。`touristappid` 仅供工具查看页面结构，不能完成真实微信登录。
3. 当前开发配置已将 `config.js` 的 `apiBaseUrl` 指向 `http://192.168.1.76:8088/api/v1`。如果后端地址变化，请同步修改该值。
4. `project.private.config.json` 已为本机开发者工具启用局域网调试并关闭合法域名校验；该文件已被 Git 忽略，不会带入发布配置。正式发布必须在开发者工具中恢复合法域名校验，并配置 HTTPS request、uploadFile、downloadFile 合法域名。真机联调时，手机必须能访问 `192.168.1.76`，否则改为手机可达的测试 HTTPS 域名。
5. `GET /public/config` 决定当前为 demo 或 live，前端不自行切换真实模式。demo 登录页显示“演示账号登录”，可用 `customer / DemoCustomer!2026`。真实环境由 `wx.login` 获得 code，Java 服务端完成 `code2session`；小程序中不保存 AppSecret、泰康密码或保险接口凭据。

## 页面

- `pages/home`：家用车、货车、摩托车入口及最近会话。
- `pages/assistant`：资料确认 → 方案报价 → 投保确认；聊天消息、上传预览、手填/识别核对、方案保额、客服转接、订单申请。
- `pages/orders`、`pages/order-detail`：按权限查询订单、搜索、状态和办理轨迹。
- `pages/me`、`pages/info`：角色组织、政策版本、积分明细、组织树、业绩预估、客户维护、历史会话和办理指南。
- `pages/login`：微信登录，以及仅 demo 环境可用的测试账号登录。

## 图片来源与隐私

- 手机相册/拍照：`wx.chooseMedia`，`mediaType:['image']`。
- 微信聊天：`wx.chooseMessageFile`，`type:'image'`。由用户主动在微信提供的选择器中选择群聊或聊天里的图片，不会自动读取群聊。
- 电脑开发者工具：选择“从电脑选择 / 拖入图片”，通过 `wx.chooseMessageFile` 选择本地图片；文件选择器打开后可从资源管理器拖入图片。上传记录标记为 `WEB`，不会伪装成聊天图片。
- 每次最多四张，单张不超过 10MB；JPG、PNG、WEBP。HEIC 等不支持格式应先转换。
- `wx.requirePrivacyAuthorize` 配合 `onNeedPrivacyAuthorization` 与原生 `agreePrivacyAuthorization` 按钮，用户可拒绝或查看官方隐私指引。
- 需在微信后台《用户隐私保护指引》准确声明资料图片、联系人及相关使用目的。上线主体、客服联系方式、保存周期等由运营方配置及发布。
- 所有图片访问均经带 Bearer 认证的 `wx.downloadFile`，取得本地临时路径再预览。不把令牌放 URL，不公开证件静态目录。

## 业务限制与防重复

- 仅泰康渠道。摩托车创建会话即人工接待；实际网关不支持的货车资料也转人工，保持同一会话和资料记录。
- 演示数据明确标注，真实模式配置错误不会降级显示假报价。识别失败打开手填表单，不补造证件信息。
- 每次报价只提交用户当前选定方案，金额输入由“万元”精确转为整数字符串“元”。默认表单保额是可修改的输入建议，不是佣金/积分规则。
- 报价请求等待上限 240 秒，不自动重试。发送前持久保存 pending key 和既有报价 ID；网络结果未知时只允许查询或转人工，避免产生重复外部订单。
- 订单申请沿用同一报价的幂等 key；不调用支付或假装出单。
- 只有人工服务/未知报价的可见会话进行 5 秒轮询，网络失败退避至 15 秒。每次可见会话最多自动接收 5 分钟，超时提供“继续接收”入口；离开/隐藏页面清除定时器。
- 后端负责最终 RBAC、归属隔离、金额、字段和幂等校验；小程序的校验与按钮显示只是交互辅助。

## 验证

```bash
node tests/validate.js
node --test tests/logic.test.js
```

离线验证覆盖 JavaScript 语法、页面文件/组件/跳转完整性、WXML 标签和事件处理、金额转换、上传规则、API 认证、报价未知状态不重发、定时器退出。它不替代微信开发者工具编译、AppID/域名验证、iOS/Android 真机的相册/微信群选图验收，也不代表已使用真实泰康账号报价。

## 正式验收建议

1. 两个不同微信账号登录后互相无法读取会话/图片/订单。
2. 相册、拍照、群聊各上传一张行驶证，取消和拒绝隐私授权后页面仍可用。
3. OCR 成功核对；识别失败手填；验证 VIN、手机号、日期和使用性质。
4. 单交、交三、全面保障各在明确授权且准备好测试资料后单笔验证。
5. 请求中断、报价结果未知不自动新建；刷新后能看到服务端状态。
6. 摩托车从创建会话到客服领取、文字图片、转接和结束；后台订单变更后小程序可见。
7. 提交申请后状态只表示人工办理进度，不冒充已付款/正式出单。
