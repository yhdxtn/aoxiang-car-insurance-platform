# 翱翔车险 · 网页人工客服前端

独立 Vue 3 + Vite 项目，与管理端使用不同标签页令牌键；只访问 Java `/api/v1`。

## 运行

```bash
npm ci
npm run dev
```

打开 `http://localhost:5174`。开发代理默认指向后端 `http://127.0.0.1:18080`；如需要，可使用环境变量 `API_PROXY_TARGET`。公开 API 基址和管理端链接见 `.env.example`。

```bash
npm test
npm run build
```

生产部署 `dist/` 静态资源，使用 HTTPS 并同域反向代理 `/api/`。不需要原企业微信桌面端、Hook 或群机器人。

仅后端 demo 模式使用 `service / DemoService!2026`。真实模式请在管理端创建人工客服账号。管理员也能进入客服端，财务/代理/普通用户无客服接待权限。

## 接待操作

1. 在左侧“待接入”选择会话，点击“接入会话”。其他客服已接入时服务端会阻止抢占。
2. 中间查看完整历史，发送文本或上传行驶证/身份证图片。原图经 Bearer 授权读取为临时 Blob URL，组件销毁时释放，不生成公开图片链接。
3. 点击资料图片“识别资料”。OCR 未配置或无法识别时，明确提示手工填写；识别字段不会自动当成客户已确认资料。
4. 右侧核对并保存车辆信息。修改将使旧报价失效；有处理中、结果未知或已提交申请的报价时限制修改。
5. 家用车请求单个泰康方案。货车不受支持时转人工；摩托车没有自动报价按钮。家用车自动报价失败、需人工核验或结果未知时，也可由已领取会话的客服登记内部人工核价申请；所有车种均须处于待接入/接待中状态且没有正在处理的外部报价，结果未知时先核对原外部单，不重发报价。
6. 在客户确认后提交投保申请，状态为待审核；此操作不会调用保司支付或自动出单。
7. 人工订单未核价时显示“待人工核价”；客服可在跟进表单录入核实保费（十进制元，最多两位小数）。登记后续业务办理进度，完成必须已核价并录入已核实的保单号。可转接其他授权客服或结束会话。

## 请求与恢复

- 聊天消息、报价、投保申请携带幂等标识。网络中断时不自动重发业务写入；报价超时先刷新查看结果，未知结果需人工核查。
- 报价记录保留本地引用和保司订单引用（后端返回时展示），帮助人工定位原业务。
- 活动可见页面每 5 秒增量读取当前会话，每 3 轮刷新队列。没有选中会话时仅刷新队列。
- 页面隐藏即停止计时并取消会话只读请求；失败指数退避至最长 60 秒；15 分钟无操作暂停刷新，需点击恢复。注销和组件销毁均停止轮询。
- 业务 POST 与轮询分开，不会因隐藏页面主动重发报价/投保。
- 客服列表按页读取，每页 30；搜索仅筛选当前页姓名/车牌，页面已明确标注。

该页面是桌面客服工作台，推荐宽度 1050px 以上；较窄屏幕可打开收起的资料面板，最小工作区宽度 600px。小程序用户端在另一个独立项目中。

## 验证

`npm test` 验证可见性轮询、空闲暂停、停止后异步返回不复活、失败退避，以及 raw JSON、Bearer、401 清会话、multipart 上传、超时不重发和请求转义。`npm run build` 验证 Vue 模板与生产构建。真实微信、保司登录/OCR/报价仍需配置后联调，demo 不伪造真实成功。
