# 翱翔车险 · 网页管理前端

独立 Vue 3 + Vite 项目。代码只访问 Java 后端 `/api/v1`，不直连保险公司，也不依赖原企业微信系统。

## 启动

要求 Node.js 20.19+ 或 22.12+（推荐 24）。在本目录执行：

```bash
npm ci
npm run dev
```

开发地址 `http://localhost:5173`，Vite 将 `/api` 代理至 `http://127.0.0.1:18080`。如后端不在本机，可设置 `API_PROXY_TARGET`。`.env.example` 给出了 API 基址和客服端链接配置；只使用 `VITE_` 非敏感公开配置，勿在前端填入微信 AppSecret、保司密码或网关密钥。

```bash
npm test
npm run build
npm run preview
```

生产静态文件在 `dist/`；由 Nginx 同域反向代理 `/api/` 至后端。请按根目录部署文档配置 HTTPS。应用使用 hash 导航，无需服务器路由回退。

## 登录

仅在后端 **demo** 模式初始化演示账号：`admin / DemoAdmin!2026`、`agent / DemoAgent!2026`。财务账号由管理员创建（demo 中若有预设财务账号，以后端 README 为准）。真实模式使用后端初始化的管理员和新增人员账号，不能套用演示账号。

登录令牌仅保存在本标签页 `sessionStorage`，退出时调用后端注销；权限失效返回 401 后清除会话。前端菜单用于交互引导，所有业务范围由后端再次验证。

## 业务页面

- 工作台：订单、客户、待人工会话、订单保费汇总及最近订单。
- 订单：搜索订单号、车牌、姓名、VIN、保单号；查看资料和状态历史；登记处理、取消、完成。
- 客户：新建、编辑、跟进备注。
- 组织：下级组织创建、名称维护和启停；树状展示可见层级。
- 人员：新建账号、设置角色及归属、修改和启停；可复制用户 ID。
- 政策：生效日期、车种、佣金比例、上级来源、逐级下发和版本保留。
- 业绩与佣金：订单快照的预估统计，不是收款或发放系统。
- 积分：本人账本；总部和财务可指定用户调整积分，带幂等键防止网络重试重复记账。
- 泰康配置：查看服务器配置状态并检查账号登录，不显示或保存保险密码。
- 操作日志与账号安全。

政策日期使用 `YYYY-MM-DD`，佣金比例按百分比输入；没有确认的业务比例不填默认值。人工订单未核价时显示“待人工核价”；仅管理员与客服可录入人工核实保费，已自动报价的保费不能在此修改。完成订单要求已核价并核实正式保单号；提交投保申请不表示自动出单或付款。积分商城兑换未实现，需先确认商品、扣减与退还规则。

## 验证

`npm test` 覆盖关键角色菜单、不可逆订单状态、政策上下级比例/有效期限制、人工核价权限与金额空值，以及 raw JSON、Bearer、401 清会话、multipart 上传、超时不重发和请求转义。完整角色/组织隔离、幂等性由后端集成测试验证。`npm run build` 检查 Vue 模板与生产构建。
